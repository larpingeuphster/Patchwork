Swaps now load as soon as RIVALS starts.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v2.0.3-Windows.exe`** below. It replaces 2.0.2.

## Why swaps took so long

Roblox only downloads an asset when the game first needs it. Patchwork swaps the cached copy a moment later, so in that first match Roblox has already loaded the original. On top of that, earlier versions put every original back when Patchwork quit (including when you shut down your PC), so every session started over, and Clear Cache wiped every swap.

## Changed

- **Swaps stay in Roblox's cache between sessions.** Once you've seen an asset in one match, every later launch of RIVALS loads your swapped version straight away.
  - This is now the default, and this update switches it off once for existing users: **Settings → Put the original assets back when Patchwork quits**.
  - **Quit** still stops new swaps, and **Settings → Put originals back** undoes them all whenever you like.
- **Faster:** Patchwork checks Roblox's cache every second instead of every two.
- **Clear Cache now warns you first** that it also deletes your swapped assets.

## What to expect

1. **First match** after adding a swap: Roblox downloads the asset and Patchwork swaps it. You'll still see the original this match.
2. **From then on**, including after restarting your PC: the swap is there as soon as RIVALS loads.

Assets that **can't be identified** (most of RIVALS' own sounds, meshes and animations, which Roblox only gives to signed-in players in the game) are listed in **Activity**.
