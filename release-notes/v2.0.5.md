Skin capture: swap RIVALS' own skins without a Roblox login.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v2.0.5-Windows.exe`** below. It replaces 2.0.4.

## New: Skins tab

RIVALS' own skins, animations and sounds are only handed out to signed-in players, so Patchwork can't look them up by asset ID (it never uses your Roblox login). Skin capture works around that by watching what Roblox loads:

1. **The skin to replace:** press **Start**, equip or view that skin in RIVALS, press **Stop**.
2. **The skin you want:** press **Start**, view that skin (the shop preview works), press **Stop**.
3. **Match the files.** Patchwork suggests a match for each file (mesh to mesh, texture to texture); change any you like, name it and save.

The captured skin is applied within a second and stays applied through Clear Cache, restarts and Roblox re-downloading the files. Switch it off or delete it to put the originals back.

Tips:
- Patchwork clears the cache when a step starts (your swaps are kept), so the skin's files show up as new. Capture in a quiet spot, like the lobby with the loadout or shop open, so other players' files don't get mixed in.
- If nothing is captured, the skin was already loaded: rejoin RIVALS and try again.

## New: cache report (for texture packs)

RIVALS stores most in-game textures as KTX2, which Patchwork can't match to texture-pack images yet. **Skins → Save cache report** writes a list of file kinds, sizes and addresses (nothing personal, and without download tokens). Sending it helps add texture-pack support.
