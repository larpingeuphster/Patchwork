A diagnostic release to find out whether Roblox now blocks asset swappers.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v1.0.8-Windows.exe`** below. It includes the 1.0.7 fix for blank images in Roblox.

## What this release checks

Roblox accepts Patchwork's certificate but then doesn't ask Patchwork for any assets. One likely reason is **certificate pinning**: Roblox checks it's talking to its own server and hangs up on anything else. Fleasion's README currently says Roblox has patched Fleasion, which would fit.

Patchwork now notices when Roblox opens a secure connection through it and then closes it without sending a request, and records which protocol Roblox used.

## What to do

1. Quit the old Patchwork from its tray icon.
2. Open 1.0.8.
3. Right-click the tray icon → **Clear Roblox cache**, then open RIVALS.
4. Play for a minute, then open an issue with what the **Activity** tab says. Look for lines like *"Roblox closed a connection … without asking for anything"* and the summary *"… connection(s) Roblox closed without a request, protocol …"*.

If those lines appear, Roblox is blocking this kind of tool. Getting around that would mean modifying the Roblox client itself, which Patchwork will not do: that's what gets accounts banned.
