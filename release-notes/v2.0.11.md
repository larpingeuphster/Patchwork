Replacer: mesh swaps now find RIVALS' compressed meshes.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v2.0.11-Windows.exe`** below. It replaces 2.0.10.

## Fixed

- **Mesh swaps by asset ID find their target.** Roblox re-encodes the meshes it gives the game (newer ones are Draco-compressed), so the cached file never matched the mesh Patchwork downloads, and those swaps waited forever. Patchwork now compares each mesh's triangle count and size instead, which survive re-encoding. A match has to be near-exact and clearly better than any other mesh, so look-alikes aren't guessed.

## What the Replacer can and can't reach

Asset-ID swaps need Patchwork to download the original asset as a signed-out visitor, to know what to look for:

- **Images and textures:** found, including RIVALS' compressed (KTX2) textures, by how they look (since 2.0.6).
- **Meshes:** found by shape (new).
- **Fonts and other files:** found when Roblox caches them unchanged.
- **RIVALS' own private assets** (Roblox answers "not authorized" without a login): can't be found by ID. Use the **Cache** tab for those: find the file by its preview and replace it directly.
