Fixes for clearing Roblox's cache, which swaps depend on.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v1.0.2-Windows.exe`** below. It replaces 1.0.1, and your profiles and settings carry over.

## Fixed

- **"Couldn't delete rbx-storage.db … being used by another process".** When something keeps Roblox's cache open, Patchwork now names the program, for example *"in use by Fishstrap (PID 1234)"*, so you know what to close. Until the cache is cleared, Roblox keeps loading the assets it saved earlier, which is why swaps didn't show.
- **Wrong "In RIVALS" status after Roblox closed.** Roblox's last log still says you're in RIVALS after the game closes. Patchwork now only shows you as in a game while Roblox is actually running.
- **Clearing the cache on Start.** Start now warns when the cache couldn't be cleared, instead of carrying on silently.

## Getting swaps to show

1. Close Roblox **and Fishstrap** (check the system tray and Task Manager).
2. Press **Clear Cache**. It should say the cache was cleared.
3. Press **Start**, then open Roblox and join RIVALS.
4. If swaps still don't show, open an issue with what the **Activity** tab says.
