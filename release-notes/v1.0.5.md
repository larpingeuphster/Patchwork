Patchwork now works like Fleasion: no Start button, it runs as administrator, and it starts with Windows.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v1.0.5-Windows.exe`** below. It replaces 1.0.4, and your profiles and settings carry over.

## Changed

- **No Start button.** Patchwork starts swapping as soon as it opens, and stops when you close it. If starting ever fails, click the status badge at the top right to try again.
- **Clear Cache is the "make it work" button.** It closes Roblox if needed and clears the assets Roblox saved. The next time you open Roblox, it goes through Patchwork.
- **Always runs as administrator.** Patchwork needs this to capture Roblox's connections. Windows asks for permission when you open it yourself.
- **Starts with Windows** (on by default). Patchwork starts minimised when you sign in, through Windows Task Scheduler, so there's no permission prompt. Turn it off in **Settings → Start Patchwork when I sign in to Windows**.
- **One copy at a time.** Opening Patchwork while it's already running brings its window back instead of starting a second copy.

## Fixed

- **Swaps where Roblox downloads assets directly.** Patchwork now also handles Roblox's content servers `fts.rbxcdn.com` and `contentdelivery.roblox.com` (the same servers Fleasion handles), not only `assetdelivery.roblox.com`. Large downloads are passed through as they arrive.
- **Better diagnostics.** Activity lists the kinds of Roblox request Patchwork sees, and the summary counts downloads from Roblox's servers.

## If swaps still don't show

1. Press **Clear Cache**.
2. Open RIVALS and play for a minute.
3. Open an issue with what the **Activity** tab says. The *"Roblox sent …"* and *"Seen from Roblox so far"* lines show exactly what Roblox is asking for.
