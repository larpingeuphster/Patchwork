## Download

Download **`Patchwork-v2.0.15-Windows.exe`** below. It replaces 2.0.14.

## New: import from the Fleasion rewrite

**Import** now offers three choices:

- **Preset file…:** one Patchwork or Fleasion `.json`, as before.
- **Configs folder…:** a Fleasion `configs` folder or a shared config pack (the JSON files with their asset folders beside them). Each config becomes a Patchwork profile.
- **From Fleasion on this PC:** shown when the Fleasion rewrite is installed (`%LOCALAPPDATA%\FleasionNT\configs`). Imports every config, switched on the way Fleasion has them.

Patchwork applies imported configs its own way, through Roblox's cache. It doesn't use or change Fleasion, and the two don't need to run together.

## The rewrite's config format, now understood

- Rules without a `mode` (they default to replacing by ID), the `"remove"` mode and the older `remove` flag.
- Pack-relative files such as `/StickObj/stick.obj`, found in the folder the config came from (or Fleasion's configs folder). `.obj` models are converted as usual.
- Configs that are just a list of rules, and files saved in UTF-16 or Windows encodings.
- Groups (`"type": "group"` with `children`), as before.

## Skipped, with a note in Activity

- Targets that are a whole asset type (such as `"Image"` or `"TexturePack"`): Patchwork swaps specific files, not every asset of a type.
- Size and length filters: the swap still applies to its asset IDs.
- `with_id` values from 0 to 80, which the rewrite treats as asset types, not IDs.
