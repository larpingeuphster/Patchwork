Fixes for Fleasion presets, plus new checks that show why swaps aren't working.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v1.0.1-Windows.exe`** below. It replaces 1.0.0, and your profiles and settings carry over.

## New

- **Remove swaps.** Type `remove` in **Replace With** to make an asset not load at all, for example to hide a map pattern or a sound. They show as **Remove** in the Mode column.
- **More of your Fleasion presets import:**
  - **Removal rules** (`id` rules with no replacement) now import as Remove swaps.
  - **`local` rules** (files on your PC) now import. If a file isn't on this PC, for example because the preset was made on someone else's computer, Patchwork keeps the swap and tells you which file is missing.
  - **Groups** (folders of rules) now import. Rules inside a group are named `Group / rule`.
  - `.obj` models still can't be imported. They need converting to Roblox's mesh format, which Patchwork can't do yet, and they're listed as skipped.
- **Export to Fleasion** now includes local-file and Remove swaps.
- **"Roblox is open" prompt.** Roblox only picks up Patchwork when it starts. If it's already open when you press **Start**, Patchwork offers to close it for you, which also lets the cache be cleared.
- **Diagnostics in Activity:**
  - whether Roblox accepted or refused Patchwork's certificate;
  - a running count of the asset requests Patchwork saw and how many it swapped;
  - any asset-server requests Patchwork doesn't handle yet;
  - a warning if you're in RIVALS but none of Roblox's asset requests reach Patchwork.

## If you imported presets in 1.0.0

Rules that 1.0.0 skipped weren't saved. Import those presets again to get them; the new copy is added as a separate profile, so delete the old one.

## Still to confirm

Swaps haven't been confirmed working in RIVALS yet, and Fleasion's own README currently says Roblox has patched Fleasion. If swaps still don't show:
1. Close Roblox, and use **Close Roblox and start** when Patchwork offers it.
2. Join RIVALS and play for a minute.
3. Open an issue with what the **Activity** tab says. The new lines there show where it's going wrong.
