Fixes the connection problem that stopped swaps from working, and lets you clear the cache with Roblox open.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v1.0.4-Windows.exe`** below. It replaces 1.0.3, and your profiles and settings carry over.

## Fixed

- **"Server TLS handshake failed. Certificate verify failed: unable to get local issuer certificate".** Patchwork connects to Roblox's real asset server on Roblox's behalf, and it only trusted its own built-in list of certificate authorities. On PCs where antivirus "HTTPS scanning" or a network filter re-signs connections, that list didn't include the certificate being used. So Patchwork refused to connect, and Roblox's asset requests never got through.
  - Patchwork now also trusts the certificates Windows trusts, the same ones your browser uses. Connections are still fully verified.
  - If a connection still can't be verified, Activity now says so plainly and explains what to change.
- **Clear Cache works with Roblox open.** Windows locks Roblox's cache while Roblox is running, so Patchwork now offers to close Roblox and clear the cache in one click.

## Getting swaps to show

1. Press **Clear Cache** (let it close Roblox if it asks).
2. Press **Start**.
3. Open RIVALS through your launcher (Froststrap, Bloxstrap or plain Roblox).
4. In **Activity**, look for *"Seen from Roblox so far: … swapped"*. If swaps still don't show, open an issue with what Activity says.
