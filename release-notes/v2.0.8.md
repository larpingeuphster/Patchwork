3D previews for meshes in the Cache tab.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v2.0.8-Windows.exe`** below. It replaces 2.0.7.

## New

- **Mesh tiles show a 3D picture** of the mesh, so you can tell which mesh is which weapon or skin.
- **Click a mesh to turn it in 3D:** drag to rotate. The details show the mesh version, vertex and triangle counts.
- Reads Roblox mesh versions 1.00 to 7.00. Meshes stored compressed (Draco) say so instead of showing a picture.

## Finding a skin's meshes

Roblox keeps a match's weapon and skin models in memory and only saves them to its cache when it downloads them. If the Meshes filter is nearly empty (for example right after Clear Cache):

1. Close Roblox completely.
2. Open RIVALS and join a match, then equip the skin.
3. **Cache → Meshes → Refresh.** The newest meshes are at the top.
