Support for Froststrap and other launchers that install Roblox somewhere unusual.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v1.0.3-Windows.exe`** below. It replaces 1.0.2, and your profiles and settings carry over.

## Fixed

- **Froststrap (and other launchers) weren't set up.** Patchwork only set up Roblox copies in a few standard places, so a launcher that keeps Roblox elsewhere launched a copy Patchwork never touched, and nothing was swapped. Now:
  - Patchwork also looks in Roaming AppData and Program Files for launcher folders.
  - **Patchwork watches where Roblox actually runs from.** When you start a game through any launcher while Patchwork is open, it notices the folder, remembers it, and sets it up, including the launcher's Modifications folder next to it.
- **New list in Settings → Roblox installs** shows every copy of Roblox Patchwork has set up.

## Setting up Froststrap (one time)

1. Open Patchwork and press **Start**.
2. Start RIVALS through Froststrap. Activity will say *"Found Roblox running from …"*.
3. Close Roblox completely, then open it again through Froststrap. From now on, that copy is set up every time you press Start.
4. If swaps still don't show, open an issue with what the **Activity** tab says.
