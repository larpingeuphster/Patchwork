Fixes from the first real run of 2.0, and a cookie-free way to find RIVALS' own assets.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v2.0.1-Windows.exe`** below. It replaces 2.0.0.

## Fixed

- **Clear Cache said Roblox's cache was "in use by Patchwork".** Patchwork kept Roblox's cache file open while watching it, and on Windows that stops the file being deleted. Patchwork now lets go of it while clearing.
- **Dozens of "Can't swap" lines.** Assets Patchwork can't identify are now reported in one grouped message, and only when the list changes. The message no longer says it's only about sounds: Roblox only hands RIVALS' own sounds, meshes and animations to signed-in players in the game.

## New

- **Finding assets through Roblox's own records.** Roblox may keep its "where is asset X" answers in the cache, with the asset ID in the address. Patchwork now reads those, so it can find an asset's cached file without downloading it from Roblox, and without a login.
- **A cache summary in Activity** when Patchwork starts, for example *"Roblox's cache has 4,210 entries (…). 380 name an asset ID, linking 350 asset(s) to their files."* That line shows whether this new lookup can find RIVALS' assets on your PC.

After a RIVALS match, open an issue (or message the developer) with the **"Roblox's cache has … entries"** line and the summary lines from **Activity**.
