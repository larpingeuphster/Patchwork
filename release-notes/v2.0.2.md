> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v2.0.2-Windows.exe`** below. It replaces 2.0.1.

## Fixed

- **Clear Cache blocked by Patchwork itself.** 2.0.1 tried to let go of Roblox's cache before clearing it, but the close silently failed: the connection had been opened on Patchwork's background thread, and Python's SQLite won't close it from another thread unless told to allow that. The file stayed open, so Windows wouldn't let it be deleted. The connection now really closes, and if closing ever fails, Activity says so instead of failing silently.
