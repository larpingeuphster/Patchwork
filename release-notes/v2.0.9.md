## Download

Download **`Patchwork-v2.0.9-Windows.exe`** below. It replaces 2.0.8.

## Fixed

- **Meshes that said "compressed (Draco)" now show a 3D preview.** Roblox's newer meshes are compressed with Draco, Google's open mesh-compression format. Patchwork now includes the Draco decoder (DracoPy), so these show as thumbnails and can be turned in 3D like any other mesh.
