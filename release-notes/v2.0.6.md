Texture packs: swaps now reach RIVALS' in-game textures (KTX2).

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v2.0.6-Windows.exe`** below. It replaces 2.0.5.

## Why texture packs didn't apply

RIVALS stores most in-game textures as **KTX2**, a compressed GPU format. Roblox only hands the KTX2 version to signed-in players, so its bytes never match the PNG anyone can download. Patchwork looked for the PNG and never found it: that's most of the "waiting" assets.

## New

- **Textures are found by how they look.** Patchwork decodes each KTX2 texture in Roblox's cache and compares a tiny thumbnail of it with the PNG of each texture-pack target. A match has to be close and clearly better than the next best, so plain or look-alike textures are left alone rather than guessed.
- **Replacements are converted to KTX2.** Your image is written at the same size, with the same number of mip levels and the same compression as the texture it replaces (BC1, BC3 or uncompressed; BC7 textures get BC3).
- **Remove** on a texture writes a transparent KTX2 texture.
- **Cache report** now lists texture formats.

## Not yet

- Textures in a format Patchwork can't read (for example Basis Universal) are named once in Activity.
- This is the first version that writes KTX2 for Roblox. If a texture shows up wrong or black, switch that swap off, then send a cache report and the Activity log.
