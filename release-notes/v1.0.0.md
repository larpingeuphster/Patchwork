The first release of **Patchwork for RIVALS**: swap RIVALS textures, skins, sounds and meshes on your own PC. Only you see the change, and only while you're in RIVALS.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Roblox's rules also forbid third-party tools that change the game, so no asset swapper can promise you won't be banned. Never use swaps that give you an advantage, try Patchwork on an alt account first, and **use it at your own risk**.

## Download

Download **`Patchwork.exe`** below and run it. It's a single file with nothing to install.

- Windows 10 or 11 is required. The window uses Microsoft Edge WebView2, which is built into both.
- **SmartScreen:** Windows may warn that the app is unrecognised, because it isn't code-signed. Click **More info → Run anyway**.
- **Permission prompt:** the first time you press **Start**, Windows asks for permission to run the redirector that captures Roblox's connections.
- **Check your download:** the SHA-256 of `Patchwork.exe` is `04efbb8ff9f8c2cb7dde0eed758e47d5a4b322766fe36cc2c64442ffd87b39b1`. Only download Patchwork from this Releases page.

## What's in 1.0.0

### Swapping
- **Three kinds of swap.** Replace an asset with:
  - another **asset ID**;
  - a **web link** to a file, which Patchwork downloads once and keeps;
  - a **file on your PC**: PNG, JPG or WEBP images, OGG or MP3 sounds, `.mesh` meshes.
- **One "Replace With" box** takes any of these and shows what it detected as you type.
- **Several IDs at once:** each swap can replace any number of asset IDs. Plain IDs, `rbxassetid://` and Roblox links all work.
- **RIVALS only.** Swaps apply only while you're in RIVALS. Patchwork reads Roblox's own log to see which game you joined, and pauses swaps everywhere else.

### Profiles and presets
- **Profiles:** group swaps into named sets and switch several on at once (**Editing** and **Enabled**, plus **New**, **Duplicate**, **Rename** and **Delete**).
- **Fleasion presets:** **Import** reads Fleasion `.json` configs (`id` and `cdn` rules). **Export** saves as a Patchwork or a Fleasion preset.
- **Safe imports:** Patchwork warns you before importing a preset that downloads files from the web, and lists the sites.
- **Portable profiles:** each profile is a `.json` file in `%APPDATA%\Patchwork\configs`, and files kept next to it travel with it.
- **Undo** (Ctrl+Z) covers every change to swaps and profiles.

### The window
- **Tabs:** Replacer, Activity and Settings, with Start/Stop and a live status badge (Stopped, Waiting for RIVALS, In RIVALS, Paused).
- **Swap table:** sortable and filterable, with an on/off switch on every swap, plus an **Add / Edit** form with **Add New**, **Load Selected** and **Update Selected**.
- **Activity:** a live feed of every swap Roblox loads, which game you're in, and any warnings, with counts for the session.
- **Look:** black and purple, with an animated loading screen, a glow that rises when you're in RIVALS, and moving waves between panels. Animations turn off if Windows is set to reduce motion.
- **Keyboard shortcuts:** Ctrl+N, Ctrl+F, Ctrl+Z, Ctrl+A, Space, Delete and Enter.

### Staying safe
- **Hands off the game and your account.** Patchwork never touches Roblox's memory and never reads your account or cookies.
- **Narrow traffic.** It only captures Roblox's own traffic, and only reads `assetdelivery.roblox.com`. Logins, chat and game servers pass straight through.
- **A certificate made on your PC.** It's added only to Roblox's own certificate list, not to Windows, and **Remove certificate** in Settings takes it out again.
- **Stop restores Roblox.** Stopping removes Patchwork's changes and clears the asset cache. You can turn this off in Settings.
- **ID-swap reminder.** Patchwork reminds you that asset-ID swaps are visible to Roblox's servers, while link and file swaps aren't.
- **Launcher support.** Works with the standard Roblox install and with Bloxstrap or Fishstrap. The Microsoft Store version isn't supported.

## Good to know
- **Clearing the cache:** Roblox reuses assets it already downloaded. If a swap doesn't show up, close Roblox, press **Clear Cache**, and join again.
- **Reporting problems:** this is the first release. If a swap doesn't work, open an issue with what the **Activity** tab says.
- **The source** is public so you can check exactly what Patchwork does. See [Why the source is public](https://github.com/larpingeuphster/Patchwork#why-the-source-is-public).
