Warns when Fleasion is undoing or blocking Patchwork's swaps.

> [!WARNING]
> **You can be banned from RIVALS for using skin changers.** Swapping weapon or character skins with Patchwork counts as one, even though only you can see it. Use Patchwork at your own risk, and try it on an alt account first.

## Download

Download **`Patchwork-v2.0.16-Windows.exe`** below. It replaces 2.0.15.

## New

Patchwork checks for two things that stop it working, when it starts and each time you join a game, and says so in **Activity**:

- **Fleasion is running.** Fleasion can delete Roblox's cache whenever it starts ("Clear Cache on Launch"), which wipes Patchwork's swaps and everything Roblox downloaded, and its proxy changes Roblox's downloads too. Quit Fleasion completely (including its tray icon) while you use Patchwork.
- **The Windows hosts file redirects Roblox's servers**, usually left by Fleasion's Hosts File mode. Patchwork then can't reach Roblox to look assets up (Activity showed "couldn't reach Roblox: SSL … EOF"). Turn that mode off in Fleasion, or remove the Roblox lines from `C:\Windows\System32\drivers\etc\hosts`, and restart your PC.

## Using configs imported from Fleasion

Configs built for Fleasion's weapon skins mostly target RIVALS' own private files (meshes, textures, sounds, animations), which Roblox only gives to signed-in players. Patchwork never uses your login, so those rules are listed as "can't be identified". Image, texture and sky rules, and rules that use files shipped in the pack, work once Roblox has downloaded the originals: play a match, then close Roblox completely and open RIVALS again. For skins, use **Cache → Watch** and replace the weapon's files with the pack's files directly.
