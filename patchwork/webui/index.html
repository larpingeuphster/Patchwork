Skin capture

RIVALS' own skins can't be looked up by asset ID without your Roblox login, which Patchwork never uses. Instead, show each skin in game while Patchwork watches which files Roblox loads, then pick which file replaces which. A mesh only replaces a mesh, a texture only a texture.

Patchwork notes every file Roblox downloads or reads while a step runs. Look at the skin for the first time this session (if you've already looked at it, close Roblox and reopen it first), in a quiet spot like the lobby with the loadout or shop open.

  1. The skin to replace. Press Start, equip or view that skin in RIVALS, then press Stop.
  2. The skin you want instead. Press Start, view that skin (the shop preview works), then press Stop.
  3. Match the files below, name the swap and save it.

Texture packs

RIVALS stores most in-game textures as KTX2, a GPU format only signed-in players are given, so its bytes never match the image Patchwork can download. Patchwork finds each texture-pack target by how it looks instead, and converts your replacement to the same KTX2 format and size.

If textures still don't change, save a cache report (file kinds, sizes, texture formats and addresses; nothing personal) and send it in.

RIVALS only

Swaps apply only while you're in RIVALS (place ). Patchwork reads Roblox's own log to see which game you joined. In any other game, Roblox loads its normal assets.

Staying safe

Patchwork never touches the game's memory or your account. It starts swapping as soon as it opens; to stop it, quit Patchwork from its tray icon.

How swaps work

Roblox saves every asset it downloads in a cache on your PC. Patchwork finds the cached copy of each asset you swap and replaces it, so Roblox shows your version the next time it loads that asset (usually your next match). It never touches Roblox's connection, the game's memory or your account, and it works the same with Bloxstrap, Fishstrap or Froststrap.

Images, sounds and skins (a mesh or model swapped for another skin's) can be swapped. 3D objects can't be removed or made invisible.
